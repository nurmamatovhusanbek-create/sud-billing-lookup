Section 1

Overview & Design System

App identity, color, glass, typography, icons, tokens

Sud Billing Lookup is a Next.js 16 single-page application that imports every court receipt (kvitansiya) issued under a company TIN from billing.sud.uz and cross-references them with the court case monitoring portal my.sud.uz. The design language is dark-glassmorphism-on-light: a cool white mesh background with four faint blue radial-gradient orbs, frosted glass panels at 60–72% white opacity, deep slate primary action buttons, and a restrained #4a90d9 blue accent.

Section 3

Bills Tab — All States

5 states · 27+ sub-components

The Bills tab is the primary surface of the application. Users enter a 9-digit company TIN (INN/STIR), the app solves the recaptcha.sud.uz proof-of-work challenge, queries billing.sud.uz/api/invoice/captcha/search, and then enriches each bill with full details (court, amount, status, case numbers) via /api/invoice/checkStatus. The tab cycles through five states: empty → loading → results (or no-results / error).

3a

Default / Empty State

Before any search

The empty state is centered around a search hero — a large glass-panel-strong with eyebrow + headline + description + INN input + Search button. Below it sits a recent-searches chip row and a 4-card feature grid.

3c

Error State

Network / API failure

When the API fails entirely (Tor can't connect, all CORS proxies are exhausted, captcha can't be solved), a destructive Alert appears with the title and message plus a Try Again button that re-runs the same search.

Failed to fetch bills

All CORS proxies (proxy.cors.sh, allorigins, corsproxy.io) are exhausted or billing.sud.uz is unreachable. Please try again in a moment.

3d

No Results State

INN has zero bills

When the search succeeds but the company has zero receipts registered, a centered empty-state card appears with an icon circle, descriptive message, and a Search another TIN CTA that clears the input and refocuses it.

No bills found

No receipts are registered under TIN 302 678 824 in the billing.sud.uz database. The company may be newly registered or hasn't paid any court fees yet.
